# Centauri Systems

> Centauri Systems is a Google Cloud Select Technology Partner with Apigee specialization. We build Launchpad, a fully managed developer portal for Apigee X and Apigee Edge, plus API observability and AI agent marketplace products for enterprise Apigee platform teams.

Launchpad is one of the four ways to run a developer portal on Apigee X, alongside the Apigee Integrated Portal, the Apigee Drupal portal, and a custom React build. It deploys in your own GCP project in 48 hours, is transactable on Google Cloud Marketplace, and counts toward GCP committed spend. Custom React components are added with the `@centaurisystems/launchpad-sdk` npm package.
